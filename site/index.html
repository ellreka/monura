Monura — Browser demo ⤢

Running on sample data — nothing is saved, and it resets on reload.

Monura is a simple app for managing tasks in Markdown.

By timing how long each task takes, you can review how your day actually went.

It aims to keep task management free-form and low-pressure, while still giving you a sustainable rhythm for tracking time.

* * *

Timer presets

Start work with a preset duration chosen ahead of time — it clarifies what you're focused on right now, similar to a Pomodoro timer.

Fully local

All data stays on your machine. You can point Monura at any folder, so it's easy to open .md files you already manage in another app.

Vim keybindings

Vim mode is built in, so you can drive nearly everything from the keyboard.
